Install Python dependencies: uv sync --locked
Ubuntu 24.04 system packages: sudo apt-get install build-essential python3.12-dev libchromaprint-tools ffmpeg
Start the application: uv run --locked network.py
Run tests: uv run --locked pytest
Configuration: config.json (or set BITRIGHT_CONFIG to an explicit JSON file)
See README.md and docs/modernization.md for details and original-project attribution.
